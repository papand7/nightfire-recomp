## 007: NightFire Remastered 1.5.0 - now on Linux (beta)

**Linux is here (beta).** Download `NightFireLauncher-x86_64.AppImage`, make it executable (`chmod +x`), run it,
choose your disc and press Install. The launcher builds the game on your PC from your own disc, just like on Windows,
and tells you the one command to install anything your system is missing. It needs a graphics card with Vulkan.

Linux is a beta: it has been tested on Linux under Windows (WSL), where it plays from the title screen into the Paris
mission, but not yet on many real Linux PCs. Please report how it runs on yours. HD texture packs and DLSS are
Windows-only for now.

**Windows:** download `NightFireLauncher.exe` and press Update, as before.
