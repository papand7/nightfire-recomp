## NightFire Remastered 1.5.7

- **macOS launcher** (a .dmg), built on a macOS runner. Unsigned: macOS asks you to allow it the first time (right-click, Open).
- **Touch controls on Windows** for a touch screen: the on-screen stick, buttons and look. Turn them on in the F1 settings window under General, **On-screen touch controls**. Android keeps them always on.
- **Tighter Movement** (Controls, Gameplay; off by default) now also quickens grenades: they fly 1.5x as fast, go off after 70% of the fuse, and fall with 1.6x gravity. The host sets it in multiplayer.
- Includes everything from 1.5.6, including the driving freeze fix.

Update the game as well as the launcher: replacing the launcher alone does not update an existing game executable. Rebuild the game from your own disc. Android users should rebuild and reimport their personal data package.

Launchers contain no game code or disc files. Build from your own disc.
