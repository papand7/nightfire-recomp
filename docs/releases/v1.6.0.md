## 007 Remastered 1.6.0: Agent Under Fire joins NightFire

- **007: Agent Under Fire** is now in the same launcher as NightFire (Windows; Linux, macOS and Android are being worked on): on foot, driving and on the mounted guns, the Vulkan renderer, aim down sights with every gun's sights lined up (the Calypso, PS100 and rocket launcher keep the game's red dot), story co-op in split screen or over the network (co-op saves your progress), and LAN multiplayer with every map, character, weapon and mode unlocked (multiplayer does not change your saved game).
- Agent Under Fire supports the European (PAL) disc in this release; the US disc's package is not in it yet.
- NightFire on macOS: MoltenVK is loaded from beside the game first, and a message explains when the renderer cannot start (macOS and Linux) instead of a silent black screen.

Downloads: Windows launcher (.exe, both games), Linux launcher (.AppImage), macOS Apple Silicon launcher (.dmg), and Android player (.apk) for NightFire; `AgentUnderFire-PAL-package.zip` is fetched by the launcher itself.

Launchers contain no game code or disc files. Build or rebuild the game from your own Xbox disc using the desktop launcher. For Android, build the private game package on your PC and import it into the Android player.
