## NightFire Remastered 1.5.14

- 3D sound: directional audio, muffling through walls, and indoor echoes. Enabled by default under Gameplay & More.
- Per-weapon aim-down-sights alignment; scoped weapons retain their scopes.
- Custom crosshairs in six colours and three sizes; hit effects with damage numbers and hurt feedback.
- macOS: fixed the first-start memory commit crash and restored compilation on macOS and Linux.
- Android: fixed the Gradle wrapper permissions for builds from a fresh checkout.
- Includes the blood stains, optional ragdolls, photo mode and rendering fixes from 1.5.13.

Downloads: Windows launcher (.exe), Linux launcher (.AppImage), macOS Apple Silicon launcher (.dmg), and Android player (.apk).

Launchers contain no game code or disc files. Build or rebuild the game from your own Xbox disc using the desktop launcher. For Android, build the private game package on your PC and import it into the Android player. Replacing the launcher alone does not update an existing game executable.
