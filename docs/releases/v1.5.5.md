## NightFire Remastered 1.5.5

- Windows and Linux launchers can build an Android data package from your own disc; the sideloaded Android app has a responsive interface.
- Fixed joypad menu navigation and restored original controller schemes. NightFire is the default for new settings.
- Optional Tighter Movement for single-player and multiplayer; network players follow the host's rule.
- Pause-menu settings apply as you change them. Light Shafts is in Graphics > Effects, with Off and strengths up to 3, independent of fog.
- Light shafts render at quarter resolution, reducing their measured cost and broad haze.
- Blood appears at character impact points; Blood and Tighter Movement are available in launcher Controls > Gameplay and in-game More Settings > Gameplay & More.
- Photo mode supports noclip and shows Bond, with a show/hide toggle.
- Added protection against recursive settings activation exhausting the guest stack.
- Includes the smaller tool downloads and incremental-build improvements from 1.5.4.

Download NightFireLauncher.exe for Windows, NightFireLauncher-x86_64.AppImage for Linux, or NightFire-Android.apk for Android. Launchers contain no game code or disc files: build from your own disc. Android remains experimental; build your personal data ZIP using the desktop launcher's Android page.

Update/rebuild the game as well as the launcher to receive the new in-game menus and gameplay fixes. Existing graphics.toml files may still have Blood switched off.
