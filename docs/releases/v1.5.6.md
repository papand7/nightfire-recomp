## NightFire Remastered 1.5.6

- Fixes a driving-renderer freeze caused by visibility queries waiting for GPU work that had not been submitted. This affects the driving executable, including Enemies Vanquished.
- Includes all controller, gameplay, Android packaging and live graphics settings improvements from 1.5.5.

Download the Windows or Linux launcher and **update/rebuild the game** to receive the fix; replacing the launcher alone does not update an existing game executable. Android users should rebuild and reimport their personal data package too. The Android app remains experimental.

Launchers contain no game code or disc files. Build from your own disc.
