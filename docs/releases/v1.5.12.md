## NightFire Remastered 1.5.12

- **Collect all textures now works:** it no longer answers "Close the game first" when the game is not running.
- **Android package:** the launcher finds an Android NDK where Android Studio, a manual install or your distribution put it. Without one it shows the commands that install it (about 600 MB, once, in WSL on Windows or a terminal on Linux).
- Includes everything from 1.5.11: the NightFire icon on the Windows launcher, Start over that really starts over, and the signed macOS launcher.

macOS: open the disk image, drag the launcher to Applications, and the first time right-click it and choose Open. If macOS says it is damaged, run `xattr -cr "/Applications/NightFire Launcher.app"` in Terminal once. Apple Silicon only; the Mac build of the game itself is untested.

Update the game as well as the launcher: replacing the launcher alone does not update an existing game executable. Rebuild the game from your own disc.

Launchers contain no game code or disc files. Build from your own disc.
