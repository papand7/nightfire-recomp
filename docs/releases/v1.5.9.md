## NightFire Remastered 1.5.9

- **macOS:** the launcher app is now signed (ad hoc), which fixes macOS calling the 1.5.8 launcher "damaged". Open the disk image, drag the launcher to Applications, and the first time right-click it and choose Open. If macOS still says it is damaged, run `xattr -cr "/Applications/NightFire Launcher.app"` in Terminal once. Apple Silicon only; the Mac build of the game itself is untested.
- **This release only has the macOS launcher.** Windows, Linux and Android are unchanged: use the 1.5.8 files from the [1.5.8 release](https://github.com/papand7/nightfire-recomp/releases/tag/v1.5.8).
- Includes everything from 1.5.8: the **Collect all textures now** button on the HD Textures page (no playing needed), and the HD texture pack tool for Linux and macOS.

Update the game as well as the launcher: replacing the launcher alone does not update an existing game executable. Rebuild the game from your own disc.

Launchers contain no game code or disc files. Build from your own disc.
