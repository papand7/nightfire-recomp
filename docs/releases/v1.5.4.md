## 007: NightFire Remastered 1.5.4 (Windows launcher)

- **Much smaller first download:** the compiler the launcher fetches is now a slimmed-down Clang with only what the
  game's build needs: about 37 MB instead of 806 MB. A first install downloads under 700 MB of tools in total.
- **Faster updates:** an update only rebuilds what changed. The game's icon no longer forces both game exes to be
  linked again every time, and the build tools keep their file dates, so switching to the new compiler does not
  rebuild everything.
- **Fixed: the install could stop at "Downloading the game's source"** and sit there. The source that ships inside
  the launcher now unpacks in seconds ("Unpacking the game's source").
- **See what is happening:** the source step shows its progress (objects, MB and speed), and tool downloads show
  their speed too.
- Checked on an existing Windows install: two updates with no source changes finished in 8–9 seconds, with
  nothing recompiled or linked. Changing toolchains still requires CMake to check the compiler and libraries again.
