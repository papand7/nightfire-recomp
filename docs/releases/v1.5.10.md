## NightFire Remastered 1.5.10

- **Start over now really starts over.** It used to remove only the downloaded source, so the launcher kept saying "Built and ready". It now also removes the installed game, the HD texture tools and the remembered build, so **Install** is offered again. Your saves, settings, HD textures and disc image are kept.
- **macOS:** the launcher is signed (ad hoc) and opens, from 1.5.9. Open the disk image, drag the launcher to Applications, and the first time right-click it and choose Open. If macOS still says it is damaged, run `xattr -cr "/Applications/NightFire Launcher.app"` in Terminal once. Apple Silicon only; the Mac build of the game itself is untested.
- Includes everything from 1.5.8: the **Collect all textures now** button on the HD Textures page (no playing needed), and the HD texture pack tool for Linux and macOS.

Update the game as well as the launcher: replacing the launcher alone does not update an existing game executable. Rebuild the game from your own disc.

Launchers contain no game code or disc files. Build from your own disc.
