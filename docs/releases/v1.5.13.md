## NightFire Remastered 1.5.13 (test build)

- **macOS (Apple Silicon): the game can now be built and run on a Mac** (first test build). The launcher installs CMake and Ninja itself and asks macOS for Apple's command line developer tools (**Install the requirements**); Vulkan comes through MoltenVK, shipped with the game. Shaders compile through glslang and points draw without geometry shaders on the Mac. Ray tracing and DLSS are off there. Please report what happens.
- **Blood that stays:** stains of blood on the floor and walls where you hit someone, dark red, kept for a minute and a half. The sparks-like puffs are darker and smaller.
- **Hide HUD keeps the sniper scope** so you can still aim.
- **Photo mode:** moving the mouse right turns the view right (it was mirrored).
- **Toon and noir outlines** no longer lag behind moving things (with TAA on).
- **Ray traced lighting** shades low-poly surfaces smoothly instead of showing every polygon.
- **Paris Prelude** from the mission list starts again (it reloaded the game).
- Includes everything from 1.5.12.

This is a test release: the update prompt of earlier versions does not offer it. Update the game as well as the launcher: replacing the launcher alone does not update an existing game executable. Rebuild the game from your own disc.

Launchers contain no game code or disc files. Build from your own disc.
