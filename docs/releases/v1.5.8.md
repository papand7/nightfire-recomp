## NightFire Remastered 1.5.8

- **HD textures without playing:** the HD Textures page has a **Collect all textures now** button. The game starts, saves the textures of every mission and multiplayer map from your disc, and closes by itself (about half a minute). Then make your pack as before.
- **HD texture packs on Linux and macOS:** the pack tool and its upscaler are now built for them too (macOS untested).
- **macOS:** the app is now signed (ad hoc), which fixes macOS calling the 1.5.8 launcher "damaged". Open the disk image, drag the launcher to Applications, and the first time right-click it and choose Open. If macOS still says it is damaged, run `xattr -cr "/Applications/NightFire Launcher.app"` in Terminal once.
- Includes everything from 1.5.7.

Update the game as well as the launcher: replacing the launcher alone does not update an existing game executable. Rebuild the game from your own disc.

Launchers contain no game code or disc files. Build from your own disc.
