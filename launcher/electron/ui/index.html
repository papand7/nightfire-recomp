Android

      
Build a game package from your own disc, copy the ZIP to your Android device, then import it in the sideloaded NightFire app.

      

        
Install the game on the Mission page first. Packaging needs Linux (WSL on Windows), Android NDK r27 or newer, clang, CMake 3.25+, Ninja, git, python3 and zip. Put the NDK under ~/Android/Sdk/ndk, or set ANDROID_NDK_HOME in the Linux environment. The first build can take 20 minutes or longer.
